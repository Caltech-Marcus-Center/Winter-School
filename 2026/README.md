# Marcus Center Winter School on Quantum Many-Body Simulation 2026

**Dates:** Monday, November 30 – Thursday, December 3, 2026
**Location:** Gates Annex B122, Caltech, Pasadena, CA
**Website:** <https://marcuscenter.caltech.edu/events/schools>

This directory holds the hands-on software exercises for the 2026 school. Each
of the five modules below pairs a lecture with a software exercise session.
The concluding module on quantum algorithms (Prof. Lin Lin, Thu Dec 3) is
lecture-only and has no exercises here.
